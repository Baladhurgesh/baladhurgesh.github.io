Bala Dhurgesh

Founding Engineer at Flotive AI. Jersey City, NJ.

I started in robotics, fascinated by how a machine perceives, reasons, and acts in the real world. That led me into computer vision and autonomy at Lucid, where I built fleet intelligence and LAVA so teams could find rare driving scenes and debug faster. The ChatGPT wave changed what I thought software could be: not another chat box, but agents that turn messy information into a workflow you can trust.

That is the work now. At Flotive AI, filings and rules become a knowledge graph with answers you can cite. The same idea pulls me toward local AI: models that stay close to you, with private context, low latency, and more control than a cloud assistant. I care about agents, retrieval, evals, and taking an ambiguous problem from zero to one.

Building

Flotive AI, a regulatory intelligence engine for permitting. We ingest messy filings, tariffs, and interconnection rules, turn them into a queryable knowledge graph with decision-tree logic, and return answers with citations so every decision is auditable.

  • Queue-driven PDF ingestion, parsing, graph extraction, embeddings, and decision logic.
  • Citation-grounded evals and cross-document benchmarks for interconnection and tariffs.
  • Built for workflows where being wrong is more expensive than being slow.

Selected work

  • StrategyBench Live benchmark · Eternis · 2025

    Public leaderboard evaluating frontier LLMs across 1,000+ multi-agent social-deduction games. Normalized deception and detection scoring. Released RL environments so other labs can reproduce and extend.

    • Built the site and ran the experiments: 6 environments, 9 models, 1,000+ simulated games.
    • Deception Index covers evil, spy, and impostor roles. Detection Index covers good, villager, and crewmate roles.
    • Cross-game ranking uses normalized ELO so models can be compared across Avalon, Secret Hitler, Werewolf, Spyfall, and Among Us.
    • Game pages explain why a model ranks where it does, not only the final score.

    Website GitHub

  • Lucid Dream Data Engine Production · Lucid · 2022 / 2025

    Fleet scenario mining, auto-annotation, and LAVA similarity search. About 6B embeddings indexed, about 5x faster retrieval, and about 70% lower annotation cost.

    • Uncertainty sampling from model probabilities, plus heuristics such as pedestrian confidence under 50% within 50 meters.
    • Trained BEVFusion on in-house camera and LiDAR data and fed those labels into human review.
    • LAVA does image-to-image and text-to-image search with metadata filters for date, vehicle, and location.
    • Also built a scalable 3D object-detection auto-annotation pipeline adopted across the autonomy org.
  • PII anonymization RL finetune · Eternis · 2025

    Small local models that replace PII without rewriting the sentence. Trained Qwen3 with SFT, then DPO, then GRPO against an LLM judge.

    • The model emits a tool call, replace_entities, and leaves public figures untouched.
    • Judge scores format, PII detection, granularity, replacement quality, and category rules, from 0 to 10.
    • About 30k samples. Qwen3-4B reached 9.55/10. Qwen3-1.7B reached 9.20/10.
    • Quantization, KV cache, and speculative decoding: time to first token under 250ms on the 1.7B and 4B models.

    Hugging Face Write-up

  • PruneWise MoE pruning · 2024

    Profiled expert routing in a mixture-of-experts LLM and pruned underused experts, especially in early layers, without hurting output quality.

    • Built token-load heatmaps, then ranked experts by load and importance.
    • Subclassed the MoE block so the forward pass routes only to kept experts, including the shared expert.
    • Outputs stayed fluent, and Hindi and Chinese behavior stayed consistent after pruning.
  • Personal Twin Voice agent · 2026

    Turn a resume and GitHub into a conversational AI twin that explains skills and summarizes projects in your voice. Built with Next.js, ElevenLabs, and a structured knowledge base.

    • Private voice sessions: the site requests a short-lived token so the ElevenLabs key never ships to the browser.
    • Knowledge base is project one-pagers: role, metrics, and what to hand off when a detail is missing.

    Devpost Write-up

  • SemSeg and monocular depth WPI · 2019 / 2021

    Scene understanding for autonomous driving: SegNet ablations on Cityscapes, and unsupervised monocular depth on KITTI.

    • SegNet global class accuracy: baseline 82.27%, stride-2 convolution 63.55%, skip connections 86.1%.
    • Skip connections kept fine detail from the encoder. Replacing max-pool with stride convolution lost it.
    • Depth model trains on 29,000 unlabeled KITTI stereo pairs with photometric, smoothness, left-right, and temporal losses. Inference about 16ms per frame.

  • Kernel-Forge 2026

    An agent that profiles an LLM workload, writes Triton kernels, and keeps a kernel only when it is correct and measurably faster.
    • The loop is profile, find the expensive op, generate a kernel, compile, test correctness, benchmark, then try again.
    • On one Qwen run on DGX Spark, throughput moved from about 205 to 220 tokens per second.
  • CatchUp 2026

    Drop a YouTube link in Slack and get a short two-host podcast back.
    • Pulls the transcript, keeps the parts you asked about, writes a dialogue, synthesizes the audio, and posts the MP3.
    • Can also save notes to Google Drive and Notion.
  • Self-improving kernel agent Cerebral Valley · 2026

    Can a model improve a GPU kernel when it can compile it, test it, and read the profiler?
    • The reward is measurement: whether it compiles, whether it is correct, and what the latency, throughput, and profiler say.
    • Feedback is from the run, not from another paragraph of advice.
  • Insightium Education

    Reads a student’s test, finds the weak concepts, and writes feedback, study material, and follow-up questions.
    • The loop is assessment, diagnosis, personalized material, then more questions.
    • Works from the answer sheet itself, including handwritten pages, instead of stopping at a score.

  • Verdictron Product research

    Start from a product or a screenshot, then ask a specific question grounded in reviews, the web, and YouTube.
    • Identifies the product, gathers reviews and transcripts, stores them for search, and answers from that material.
    • Retrieval is the relevant passage, not the whole video.

  • DataGen Synthetic data

    A larger model writes examples for a task, a verifier throws out the bad ones, and a smaller model trains on what is left.
    • Generation alone is not the pipeline. It also checks, filters, and evaluates before the next round of examples.

  • MathMatrixMovies Math explainers

    Writes Manim code for a math explainer at a chosen level and language, runs it, and repairs the code when the render fails.
    • The loop is generate, execute, read the failure, repair, and run again.
    • The failed and fixed programs are pairs that could train a smaller model for animation code.

    A smart-glasses prototype: a camera reads the scene, and speech tells a visually impaired user what is there.
